  • Learn to solve for eigenvalues from characteristic polynomial
  • Find eigenvectors by solving (A - λI)x = 0
  • Work with exact rational arithmetic (fractions, not decimals!)
  • Verify the relationship Av = λv
  • Apply to diagonalization and transformations

📋 Complete Procedure

  1. Matrix Input: Enter square matrix A (2×2 or 3×3). Use integers or fractions like 1/2, -3/4
  2. Find Eigenvalues:
    • Form characteristic polynomial det(A - λI)
    • Solve characteristic equation = 0
    • Get eigenvalues λ₁, λ₂, ... as exact fractions
  3. Find Eigenvectors:
    • For each λᵢ, solve (A - λᵢI)x = 0
    • This is a homogeneous system!
    • Get eigenvector vᵢ
  4. Verify: Check that Av = λv for each pair
💡 Key Concept: Using rational numbers ensures exact solutions with no rounding errors! This reveals the true mathematical structure of eigenspaces.

📚 Theory & Concepts

What are Eigenvalues & Eigenvectors?
For a square matrix A, if there exists a non-zero vector v such that:

Av = λv

Then λ is an eigenvalue and v is the corresponding eigenvector.

Finding Process:

  1. Characteristic Equation: det(A - λI) = 0
  2. Solve for λ: Get eigenvalues (exact fractions!)
  3. For each λ: Solve (A - λI)x = 0
  4. Verify: Check Av = λv
Why Exact Arithmetic? Rational numbers reveal the true algebraic structure without approximation errors. Perfect for learning!
